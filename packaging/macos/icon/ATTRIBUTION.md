# Cartografiler application icon

The requested iDisk icon is from **BeOS Icons**, listed by StudioTwentyEight:
https://www.softicons.com/system-icons/beos-icons-by-studiotwentyeight/idisk-icon

Mac version by **Matthew McClintock**, Windows conversion by **KoL (Francisco Ocasio)**.
The original `Readme.doc` identifies the **Design Science License**; `LICENSE.txt`
contains that license (https://www.gnu.org/licenses/dsl.html).

The downloaded `iDisk.png` and `iDisk.ico` are supplied here as source data alongside
the original readme. Cartografiler's modification is format conversion to ICNS with
Lanczos resizing for larger macOS icon sizes, published as **Cartografiler application icon**. The artwork has not been redrawn.
